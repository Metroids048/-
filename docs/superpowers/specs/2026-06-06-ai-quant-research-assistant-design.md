# AI量化投研助手产品方案

## Summary

面向 A股/ETF 散户小白，构建一个“AI交易员助理”：帮助用户完成画像、看盘、策略生成、回测、预警与复盘，但不替用户决策或自动下单。产品核心不是“AI喊买卖”，而是“AI解释 + 规则回测 + 风控证据 + 人工确认”。

## Product Modules

- 新手画像：风险偏好、关注 ETF/行业、交易周期、最大回撤承受度。
- AI看盘：每日市场状态、热点 ETF、风险提示、可解释信号卡。
- 策略实验室：自然语言输入策略，系统转为结构化规则，用户可回测。
- 回测报告：收益率、最大回撤、胜率、夏普、交易次数、样本区间、失效条件。
- 预警中心：价格、指标、策略触发提醒，只提醒不自动下单。
- 复盘日志：记录用户观察、策略触发、人工操作和结果。

## API And Data Contracts

- `StrategySpec`：标的池、入场规则、出场规则、仓位规则、回测区间。
- `BacktestResult`：收益、回撤、胜率、夏普、交易次数、交易明细、风险说明。
- `SignalCard`：触发原因、证据指标、置信等级、风险反例。
- API：`/api/market/summary`、`/api/strategy/compile`、`/api/backtests`、`/api/alerts`、`/api/journal`。

## Safety And Compliance

系统定位为投研辅助和教育工具，不输出保收益、必中、跟单赚钱、自动下单等表达；LLM/AI 只负责解释、策略草稿和报告生成，指标计算和回测由确定性代码完成。所有信号都必须包含风险提示和人工确认语义。

## Acceptance Criteria

- 新用户能在 5 分钟内完成“添加标的 → 生成策略 → 查看回测 → 设置预警”。
- 固定样本数据下，回测收益、回撤、交易次数和手续费计算稳定可测。
- API 和 UI 均不出现收益承诺或确定性买卖建议。
- 停牌、缺失行情、市场休市、接口超时等场景有可理解的降级提示。
