# MVP功能拆解清单

## 1. P0：必须完成的闭环

P0目标：用户能完成“创建策略 -> 回测 -> 加入模拟盘 -> 查看策略卡和榜单”。

### 1.1 策略工厂

功能：

- 用户输入自然语言策略想法。
- 选择市场：A股/ETF。
- 选择或填写标的。
- AI生成结构化规则。
- 用户确认规则。

依赖：

- LLM网关。
- 合规过滤。
- StrategySpec对象。

验收：

- 不能输出买卖建议。
- 输出必须能转为可执行规则。
- 规则不完整时提示用户补充。

### 1.2 回测实验室

功能：

- 使用StrategySpec运行回测。
- 展示收益、回撤、胜率、波动、换手、交易次数。
- 展示手续费、滑点、样本区间。
- 展示过拟合提示。

依赖：

- 行情数据。
- 交易日历。
- 回测引擎。

验收：

- 固定数据下结果可重复。
- 数据不足时不生成结果。
- 回测结果不承诺未来收益。

### 1.3 虚拟模拟盘

功能：

- 创建虚拟账户。
- 默认虚拟本金100000元。
- 策略加入模拟盘。
- 盘后更新虚拟持仓、成交、现金、权益曲线、回撤。

依赖：

- 回测通过。
- 模拟撮合引擎。
- 数据质量检测。

验收：

- 不接真实资金。
- 不接券商。
- 不提供跟单按钮。
- 策略暂停后不再生成虚拟成交。

### 1.4 策略详情页

功能：

- 策略逻辑。
- 回测摘要。
- 模拟盘摘要。
- 虚拟持仓摘要。
- 风控事件。
- 风险反例。
- 失效条件。

依赖：

- StrategySpec。
- BacktestReport。
- SimulationRun。

验收：

- 用户能区分回测和模拟。
- 页面固定显示免责声明。
- 不展示实时跟买引导。

### 1.5 策略榜单

功能：

- 模拟表现榜。
- 稳定性榜。
- 风控榜。
- 长跑榜。

依赖：

- StrategyScore。
- SimulationRun。

验收：

- 榜单只展示虚拟模拟表现。
- 不使用“赚钱榜”“跟买榜”。
- 入榜策略必须满足运行天数和数据完整度要求。

### 1.6 合规过滤

功能：

- 检查用户输入。
- 检查AI输出。
- 检查策略解释。
- 检查付费页文案。

依赖：

- 禁止词库。
- 替代表达。
- 审计日志。

验收：

- 拦截买入、卖出、加仓、目标价、稳赚、跟着买等表达。
- 输出替代表达。
- 保留审计记录。

### 1.7 数据源透明与基础扩展

功能：
- 接入AKShare、efinance、qstock、BaoStock作为P0免费数据源。
- 建立数据源注册表，记录来源、授权口径、最近同步时间、质量状态。
- 支持行情、ETF/基金、指数、行业、基础财报、公告摘要的最小数据闭环。
- 巨潮/交易所公告先存标题、摘要、链接、发布时间、关联标的和风险标签。
- 多源冲突时标记为 `conflict`，不生成确定结论。

依赖：
- MarketDataProvider。
- FundDataProvider。
- AnnouncementProvider。
- FinancialReportProvider。
- IndustryProvider。
- source_registry和data_quality_logs。

验收：
- 用户可见数据页面展示来源和更新时间。
- 数据不足或冲突时不让AI硬生成解释。
- 公告和财报保留来源链接。
- 个股信息只作为背景和风险标签，不进入推荐链路。

### 1.8 AI问答最小版本

功能：
- 全站右下角“问问Alpha”入口。
- 策略详情页“问这个策略”。
- 风险卡页“解释这个风险”。
- 知识库页“继续追问”。
- 基于知识库、策略、回测、模拟盘、风险卡进行RAG回答。
- 高风险买卖问题规则拒答。
- 记录用户问题和反馈。

依赖：
- Qwen3 8B/14B或轻量Qwen模型。
- Qwen3-Embedding或BGE-M3。
- Qwen3-Reranker或BGE Reranker。
- PostgreSQL + pgvector。
- ComplianceGuard。

验收：
- 普通问题带引用回答。
- “现在能买吗/推荐股票/跟哪个策略买”必须拒答。
- 无依据时回答“暂无足够依据”。
- 用户问题进入后台沉淀列表。

## 2. P1：增强留存和商业化

### 2.1 观察列表

- 收藏策略。
- 收藏基金/ETF。
- 查看同一策略历史变化。

### 2.2 策略周报

- 每周生成策略表现摘要。
- 展示模拟收益、回撤、交易、风控事件。
- 给出失败原因和改进方向。

### 2.3 市场解释和风险卡

- 市场温度。
- 行业温度。
- 基金/ETF风险卡。
- 用于解释策略背景，不作为核心付费点。

### 2.4 数据与问答增强

- 行业ETF映射。
- 财报解释卡。
- 公告风险事件卡。
- 数据源状态页。
- AI问答追问、多轮上下文、用户反馈闭环。
- 每周高频问题自动汇总为知识库选题。

### 2.5 付费内测

- Free：1个策略、有限回测。
- Standard：更多策略、更多模拟账户、周报。
- 统计付费转化和取消原因。

## 3. P2：验证后再做

- 缠论结构图层。
- 波浪可能路径。
- 多策略组合模拟。
- 批量参数扫描。
- 创作者策略主页。
- 高级风控诊断。
- 更长历史数据。

## 4. 不做清单

V1明确不做：

- 实盘。
- 自动下单。
- 券商连接。
- 跟单。
- 策略作者收费订阅。
- 收益分成。
- 个股推荐。
- 目标价。
- 秒级实时行情。
