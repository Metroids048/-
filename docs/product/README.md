# AI量化投研 + 模拟盘产品材料索引

这组文档用于产品开发前的方向确认、评审和后续交付拆解。当前版本已经从“纯投研解释工具”升级为 **投研解释 + AI量化模拟盘融合产品**。

## 当前产品定位

产品暂定名：**Alpha模拟场**。

一句话定位：

> 用虚拟资金验证AI量化策略，让策略先在模拟盘里跑出证据。

产品不推翻上一版能力，而是调整主次：

- 核心付费价值层：AI策略生成、回测、模拟盘、策略榜单、复盘报告。
- 信任与解释辅助层：市场解读、基金/ETF风险卡、行业温度、知识库。
- 合规边界：只做虚拟资金模拟和策略研究，不做荐股、不做投顾、不接真实资金、不自动下单、不提供跟单按钮。

首发市场：**A股/ETF优先**。

## 当前决策

- 首页优先展示模拟盘榜单、正在运行策略、策略表现和产品边界，市场解释作为辅助区块。
- 用户主流程为：输入策略想法 -> AI生成规则 -> 回测 -> 加入模拟盘 -> 持续观察 -> 收藏/复盘/付费扩容。
- 付费点从“市场解释会员”改为“策略容量、回测次数、模拟账户、复盘报告、Alpha模板库”。
- 本地 alpha 资产用于策略灵感、策略族标签、过拟合警报和内容生产，不直接把复杂公式暴露给用户。
- 当前持仓和虚拟成交建议盘后或延迟展示，避免被理解成实时跟单信号。
- 数据底座继续扩展到行业、个股背景、财报、公告、新闻、监管公开信息，并在用户侧展示来源、更新时间和质量状态。
- 新增AI问答入口“问问Alpha”，只基于站内知识库、结构化数据和可引用资料回答；买卖建议、目标价、跟单问题必须拒答。
- 用户问题本身也是产品资产，需要沉淀为知识库选题、策略模板需求、数据源缺口和合规样本。
