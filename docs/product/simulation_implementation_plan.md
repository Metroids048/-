# AI量化投研 + 模拟盘融合实施计划

## 1. 实施目标

在不推翻上一版投研解释能力的前提下，新增并前置模拟盘能力，让产品从“解释型工具”升级为“AI策略模拟实验场”。

交付重点：

- 策略生成。
- 回测。
- 虚拟资金模拟。
- 策略榜单。
- 策略卡。
- 合规边界。
- 付费内测验证。
- 数据与资讯管线。
- 知识库与RAG。
- 竞品可借鉴能力落地。

## 2. 开发前准备交付物

开发前必须完成并冻结以下文档，避免进入开发后反复改方向：

- 产品总蓝图：明确定位、用户、功能主次、商业化和红线。
- V1 PRD：明确页面、主流程、状态、异常、埋点和验收标准。
- 技术架构方案：明确前后端、任务队列、数据库、数据源、AI层和部署方式。
- API与数据契约：明确核心接口、对象字段、状态枚举和错误语义。
- 量化策略引擎方案：明确策略规则、回测、模拟撮合、评分和模板。
- 数据与资讯管线方案：明确行情、基金/ETF、资讯、交易日历、数据质量和降级。
- 知识库与RAG方案：明确内容结构、检索方式、引用要求和合规回答。
- 竞品与开源调研：明确学什么、不学什么、V1如何取舍。

## 3. 阶段拆解

### Phase 0：方向合并与文档修订

目标：完成产品文档统一。

已确定：

- 模拟盘为核心付费价值层。
- 市场解释、风险卡、行业温度、知识库为辅助层。
- 首发市场为A股/ETF。
- 不做实盘、不接券商、不跟单。

输出：

- 融合版产品总蓝图。
- V1 PRD。
- 合规与商业化手册。
- 4周验证路线图。
- 本实施计划。
- 技术架构、API契约、量化引擎、数据资讯、知识库、竞品调研六份专项文档。

### Phase 1：策略内容验证

目标：不用完整系统，先验证“模拟盘内容”是否有人围观。

任务：

- 生成10个策略卡。
- 每个策略卡写清逻辑、回测、模拟规则、风险反例。
- 发布短视频/图文。
- 收集用户策略想法。

验收：

- 收集50条策略想法或问题。
- 有用户连续追踪同一策略。
- 用户不只问“现在买什么”。

### Phase 2：MVP模拟盘

目标：做出可用闭环。

页面：

- 首页。
- 创建策略页。
- 回测页。
- 模拟盘页。
- 策略详情页。
- 策略榜单页。
- 市场解释和风险卡辅助页。
- 知识库问答页。

后端能力：

- 策略规则解析。
- 历史数据获取。
- 指标计算。
- 回测。
- 虚拟撮合。
- 盘后模拟更新。
- 合规过滤。
- 数据质量检测。
- 资讯抓取和摘要。
- 知识库检索。

默认技术：

- AKShare + efinance/qstock 获取A股/ETF数据。
- vectorbt 做回测。
- 自建日线虚拟撮合引擎。
- LLM只做策略草稿、解释和复盘。
- PostgreSQL保存用户、策略、回测、模拟和榜单数据。
- Redis + RQ/Celery处理异步回测、盘后模拟、资讯抓取和周报。

开发顺序：

1. 数据层和交易日历。
2. 策略规则对象和合规过滤。
3. 回测引擎。
4. 模拟盘引擎。
5. 榜单评分。
6. 前端核心页面。
7. 知识库和资讯摘要。
8. 付费权益和埋点。

### Phase 3：付费内测

目标：验证用户是否为模拟盘能力付费。

价格：

- 19.9元/7天。
- 或69-99元/月。

权益：

- 更多策略。
- 更多回测。
- 更多模拟账户。
- 策略周报。
- 风控诊断。
- Alpha策略模板库。

验收：

- 20-50人真实付费。
- 付费用户使用2次以上。
- 付费动机不是跟单，而是跑策略、看模拟、做复盘。

### Phase 4：增强版

验证通过后再做：

- 多策略组合模拟。
- 缠论/波浪图层。
- 批量参数扫描。
- 创作者策略主页。
- 策略周报自动化。

暂不做：

- 策略作者收费。
- 跟单。
- 实盘接口。
- 收益分成。

## 3. P0功能清单

### 策略工厂

- 输入一句话策略。
- AI生成结构化规则。
- 用户确认规则。
- 进入回测。

### 回测实验室

- 计算收益、回撤、胜率、波动、换手、交易次数。
- 展示费用和滑点假设。
- 输出过拟合提示和失效条件。

### 模拟盘

- 创建虚拟账户。
- 默认虚拟本金100000元。
- 盘后更新持仓、成交、权益曲线。
- 展示状态：运行中、暂停、失效、数据不足。

### 策略榜单

- 模拟表现榜。
- 稳定性榜。
- 风控榜。
- 长跑榜。

### 合规过滤

- 禁止买卖建议。
- 禁止收益承诺。
- 禁止跟单暗示。
- 所有策略页显示免责声明。

## 4. P1/P2功能

P1：

- 观察列表。
- 策略周报。
- 基金/ETF风险卡。
- 行业温度。
- 付费内测。

P2：

- 缠论结构图层。
- 波浪可能路径。
- 多策略组合。
- 创作者主页。
- 高级风控诊断。

## 5. 测试与验收

产品验收：

- 用户5分钟内完成创建策略、回测、加入模拟盘。
- 用户能区分回测、模拟盘和真实投资。
- 首页不会被理解成荐股软件。

回测验收：

- 固定数据下结果可重复。
- 手续费和滑点改变会影响结果。
- 缺数据不生成虚假结果。

模拟盘验收：

- 虚拟现金、持仓、市值、权益曲线计算正确。
- 策略暂停后不再生成虚拟成交。
- 数据缺失时显示“数据不足”。

合规验收：

- 全站无收益承诺。
- AI不输出明确买卖建议。
- 榜单不出现推荐跟买。
- 付费页不暗示赚钱能力。

商业验收：

- 统计策略创建率。
- 统计加入模拟盘率。
- 统计策略收藏率。
- 统计同一策略复访率。
- 统计付费转化率。
- 统计取消原因。

## 6. 开发优先级

P0必须先做：

- 策略规则编译。
- 回测。
- 虚拟模拟账户。
- 盘后模拟更新。
- 策略详情页。
- 榜单。
- 合规过滤。
- 数据质量状态。

P1再做：

- 风险卡和市场解释。
- 资讯摘要。
- 知识库问答。
- 策略周报。
- 付费内测权益。

P2延后：

- 缠论/波浪图层。
- 多策略组合。
- 批量参数扫描。
- 创作者主页。
- 更复杂AI模型研究。
