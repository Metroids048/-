# Alpha模拟场合规与商业化手册

## 1. 核心原则

产品第一版是 **虚拟资金模拟 + 策略研究工具**，不是荐股软件、投顾服务、自动交易系统。

可以收费卖：

- 策略容量。
- 回测次数。
- 模拟账户数量。
- 复盘报告。
- 风控诊断。
- Alpha策略模板库。
- 教育内容。

不能收费卖：

- 个股买卖建议。
- 实时买卖信号。
- 当前持仓跟单。
- 目标价。
- 收益承诺。
- 自动下单。
- 收益分成。

## 2. 功能红线

绝对不做：

- 接真实资金。
- 充值参与交易。
- 连接券商下单。
- 自动下单。
- 跟单按钮。
- 代客理财。
- 收益分成。
- 策略作者收费带单。

谨慎做：

- 当前虚拟持仓展示。
- 虚拟成交展示。
- 策略榜单。
- 缠论/波浪买卖点图层。
- 策略作者公开主页。

可以做：

- 虚拟资金模拟。
- 历史回测。
- 策略规则生成。
- 策略表现榜。
- 稳定性榜。
- 风控榜。
- 盘后模拟周报。
- 风险反例。

## 3. 文案规则

### 禁止表达

- 建议买入。
- 建议卖出。
- 跟着买。
- 今日买点。
- 实时信号。
- 目标价。
- 必涨。
- 稳赚。
- 保证收益。
- 收益翻倍。
- 低风险高收益。
- AI自动赚钱。

### 推荐表达

- 触发了策略规则。
- 模拟盘虚拟持仓变化为。
- 历史回测表现为。
- 当前策略处于观察状态。
- 当前策略模拟回撤扩大。
- 该策略存在过拟合风险。
- 该结果仅为虚拟资金模拟。

### 标准免责声明

所有策略详情、回测报告、模拟盘和榜单页面固定展示：

> 本页面仅用于虚拟资金模拟、策略研究和投资者教育，不构成任何证券投资建议，不接入真实资金，不提供自动交易或跟单服务。回测和模拟表现不代表未来收益，市场有风险，用户需独立决策。

## 4. 榜单合规

允许榜单名称：

- 模拟表现榜。
- 稳定性榜。
- 风控榜。
- 长跑榜。
- 低回撤榜。
- 失效案例榜。

禁止榜单名称：

- 赚钱榜。
- 牛股榜。
- 跟买榜。
- 必胜策略榜。
- 收益王。

榜单展示规则：

- 必须显示运行天数。
- 必须显示最大回撤。
- 必须显示“虚拟模拟表现”。
- 不展示“推荐跟随”。
- 不提供复制下单。

## 5. 当前持仓与成交展示

建议规则：

- 当前虚拟持仓盘后展示。
- 虚拟成交可延迟展示。
- 若展示当日触发规则，必须写成“策略规则触发”，不能写成“买入/卖出建议”。
- 付费版也不能售卖实时跟单信号。

## 6. 商业化方案

### 免费版

权益：

- 查看公开策略榜单。
- 创建1个策略。
- 每日有限回测次数。
- 查看延迟模拟盘表现。
- 基础市场解释和风险卡。

### 标准版

价格：69-99元/月。

权益：

- 创建更多策略。
- 更多回测次数。
- 策略持续模拟。
- 策略复盘报告。
- 观察列表和提醒。
- Alpha策略模板库。

### Pro版

价格：199-399元/月，验证通过后再上。

权益：

- 多策略组合模拟。
- 批量参数扫描。
- 高级技术结构图层。
- 高级风控诊断。
- 更长历史数据。
- 导出报告。

### 暂不开放的商业模式

- 策略作者收订阅费。
- 用户按策略跟单。
- 收益分成。
- 实盘交易接口。

## 7. AI输出拦截

拦截词：

- 买入。
- 卖出。
- 加仓。
- 清仓。
- 目标价。
- 稳赚。
- 必涨。
- 跟着买。
- 抄底。
- 翻倍。

替代表达：

- 触发了策略规则。
- 进入观察状态。
- 历史回测表现为。
- 模拟盘虚拟持仓变化为。
- 当前策略风险上升。

## 8. 高风险用户问题处理

用户问“现在能买吗”：

> 我不能提供买卖建议。可以帮你查看该策略在虚拟模拟中的状态、历史回测表现和风险反例。

用户问“可以跟这个策略买吗”：

> 当前产品不提供跟单服务。策略表现仅为虚拟资金模拟，不代表真实投资结果。

用户问“这个策略能赚多少”：

> 回测和模拟只能展示历史或虚拟表现，不代表未来收益。系统会展示收益、回撤、交易次数和失效条件。
