# CONTENT_PLAYBOOK.md

## 目标

通过“投资想法体检卡”稳定产出可传播财经内容，优先追求流量、互动和分享，不追求荐股或交易转化。

## 每日执行节奏

1. 选 5 个热点想法（追涨 / 抄底 / 亏损复盘）。
2. 在体检器生成诊断卡与风险反例。
3. 每个想法产出 1 套小红书文案和 1 条短视频脚本。
4. 发布后记录互动数据（收藏、评论、分享、停留）。
5. 复盘高互动内容，沉淀到模板库。

## 内容骨架

- Hook：热点情绪切入
- Main explanation：体检结论与历史样本
- Risk reminder：风险反例与情绪提醒
- Disclaimer：不构成投资建议

## 禁用表达

- 赚钱、稳赚、必胜
- 买入、卖出、目标价
- 跟着买、荐股、带单
- 翻倍、无风险、保收益

## 推荐表达

- 想法体检
- 历史回放
- 风险反例
- 情绪提醒
- 小白提醒
- 不构成投资建议

## 发布后看板

- 体检卡生成次数
- 输入完成率
- 结果页停留时长
- 截图/复制点击率
- 评论引导点击率
