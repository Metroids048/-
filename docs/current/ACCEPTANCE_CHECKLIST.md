# ACCEPTANCE_CHECKLIST.md

## 产品验收

- [ ] 首页一句话能说明产品价值（看到热点想买？先让 AI 体检一下）。
- [ ] 首页能看到合规边界。
- [ ] 首页只有一个主 CTA（生成想法体检卡）。
- [ ] P1/P2 模块没有堆在首页。
- [ ] 用户能理解完整流程：输入想法 -> 体检卡 -> 热点榜 -> 分享内容。

## 功能验收

- [ ] 用户能输入投资想法。
- [ ] 能生成想法体检卡（含想法类型、情绪标签）。
- [ ] 虚拟样本回放标注 `replay_type: demo_virtual_sample`。
- [ ] 能展示风险反例与小白提醒。
- [ ] 能查看今日热点体检榜。
- [ ] 能生成小红书/短视频/公众号分享内容。
- [ ] 能复制分享文案。

## 前端验收

- [ ] loading 状态存在。
- [ ] empty 状态存在。
- [ ] error 状态存在。
- [ ] 移动端布局可读。
- [ ] 按钮主次清晰。
- [ ] 体检卡适合截图分享。
- [ ] 没有无效按钮。

## 后端验收

- [ ] `/api/v1/health` 可用。
- [ ] P0 API 返回结构稳定。
- [ ] 错误返回有明确 message。
- [ ] demo 虚拟回放有 `replay_type` 标记。
- [ ] 不输出投资建议。

## Agent 验收

- [ ] `AGENTS.md` 存在。

- [ ] `README.md` 与实际入口一致（FastAPI + app/static @ :8000）。
