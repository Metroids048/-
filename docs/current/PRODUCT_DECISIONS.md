# PRODUCT_DECISIONS.md

## 已锁定决策

- 当前执行版本是 `app/static` + `apps/api/alpha_sim`。
- 产品定位从“Alpha模拟场”收敛为“AI投资想法体检器”。
- 当前主目标是流量、互动和分享，不是付费转化。
- `apps/web` 是 P2/future，不参与当前 MVP 验收。
- 首页只服务体检卡主链路，不承载完整知识库、市场解释、风险卡、Ask Alpha、商业化或多市场扩展。
- `docs/current` 是当前执行版本；`docs/product` 是历史材料。
- `参考内容/` 只允许用于理解产品形态，不允许复制大段第三方代码。

## 新 P0 主链路

输入投资想法
→ AI 拆解想法类型
→ 虚拟样本回放（demo_virtual_sample）
→ 风险反例
→ 小白提醒
→ 分享内容生成

## 降级链路

以下链路保留但降级，不作为首页主卖点：

策略编译
→ 回测
→ 虚拟模拟盘
→ 榜单

## 产品边界

- 只做投资想法复盘、虚拟样本回放和内容生成。
- 不接真实资金。
- 不接券商。
- 不自动下单。
- 不提供跟单按钮。
- 不构成投资建议。
- 不承诺收益。
- 不输出目标价或明确买卖指令。

## 文案禁用词

- 赚钱、稳赚、必胜
- 买入、卖出、目标价
- 跟着买、荐股、带单
- 翻倍、无风险、保收益

## 推荐表达

- 投资想法体检
- 虚拟样本回放
- 风险反例
- 情绪提醒
- 小白提醒
- 不构成投资建议

## 技术边界

- 当前后端启动命令：`py -3 -m uvicorn apps.api.alpha_sim.main:app --reload --port 8000`。
- 当前前端由 FastAPI 根路径 `/` 挂载 `app/static/index.html`。
- 不新增生产依赖，除非明确说明不可替代原因并同步测试。
- 修改 API 契约时，必须同步更新前端渲染和测试。
