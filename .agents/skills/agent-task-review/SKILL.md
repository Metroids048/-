# Agent Task Review

## Review checklist

Before final response, verify:

- Did I follow `AGENTS.md`?
- Did I stay within P0 unless explicitly told otherwise?
- Did I avoid modifying both `app/static` and `apps/web`?
- Did I avoid adding new dependencies?
- Did I preserve compliance boundaries?
- Did I run tests?
- Did I explain untested areas?
- Did I update docs if behavior changed?

### Files changed
