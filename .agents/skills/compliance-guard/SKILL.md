# Compliance Guard

## Must block

- Guaranteed return
- Buy/sell instruction
- Target price
- Copy trading
- Real-money trading
- Broker connection
- Profit-sharing
- High-win-rate promise

## Required disclaimer

All user-facing diagnosis and content must include:
仅用于投资想法复盘、历史样本回放和内容生成，不构成投资建议。

## Final check

Before finalizing, list:
1. Forbidden terms removed
2. Disclaimer present
3. No buy/sell advice
4. No return promise
