# Traffic Content Generator

## Content formats

- Xiaohongshu title
- Xiaohongshu body
- Short video script
- Public account paragraph
- Screenshot caption
- Comment prompt

## Rules

Never use:
- 赚钱
- 稳赚
- 买入
- 卖出
- 目标价
- 跟着买
- 牛股
- 荐股

Prefer:
- 体检
- 历史回放
- 风险反例
- 情绪提醒
- 不构成投资建议

## Output format

Each content output must include:
- Hook
- Main explanation
- Risk reminder
- Disclaimer
