# Idea Diagnosis Product

## Current positioning

AI投资想法体检器：看到热点想买？先让 AI 体检一下。

## P0 flow

Input idea
→ Diagnose idea type
→ Historical replay
→ Risk counterexamples
→ Xiaobai reminder
→ Shareable content

## Forbidden

- Buy/sell advice
- Target price
- Guaranteed returns
- Copy trading
- Broker connection
- Real money
- 7-day observation as main selling point
- Complex quant jargon on homepage

## Required output

Every product change must state:
1. Which user type it serves
2. Which P0 step it improves
3. How it helps traffic or sharing
4. Compliance risks
